# Video Conferencing Platform

A full-stack video conferencing platform built with modern web technologies, featuring real-time communication, user authentication, post sharing, connection management, and profile functionality.

## 🚀 Features

### Core Video Conferencing

- Real-time video/audio communication
- Screen sharing capabilities
- Chat functionality during calls
- Participant management

### User Management

- User registration and authentication
- Profile creation and management
- Profile picture upload with Multer
- Work history and resume functionality

### Social Features

- Post creation and sharing
- Comment system on posts
- User discovery and connections
- Connection requests and management
- Like and share functionality

### Profile & Networking

- Complete user profiles
- Connection request system
- Resume download functionality
- Work history management
- User profile navigation

### Technical Features

- Server-side rendering with NextJS
- Redux state management
- Responsive design
- PDF generation and download
- API integration

## 🛠️ Technology Stack

### Frontend

- **NextJS** - React framework with SSR/SSG
- **React** - UI library
- **Redux** - State management
- **Pure CSS** - Styling system
- **BundlePhobia** - Bundle optimization

### Backend

- **Node.js** - Runtime environment
- **Express** - Web framework
- **Mongoose** - MongoDB ODM
- **Multer** - File upload handling
- **JWT** - Authentication

### Database

- **MongoDB** - NoSQL database

### Deployment

- Platform-agnostic deployment ready
